# EduPredict AI — Student Performance Predictor

A Streamlit + scikit-learn project for a GDG on Campus ML interview portfolio.

## Features
- Random Forest regression model
- Interactive student profile inputs
- Predicted score estimate and performance band
- Personalized rule-based study suggestions
- MAE, RMSE and R² evaluation on a held-out test split
- Feature importance chart and demo dataset preview
- Responsible-use and model-limitations page

## Important data note
The first version generates synthetic demonstration data from an illustrative formula. It is meant to demonstrate an end-to-end ML workflow, not to make valid predictions about real students. Do not use the output for grading, admissions, discipline, or other high-stakes decisions.

## Run on Windows (VS Code)
1. Install Python 3.10+ and VS Code.
2. Extract the ZIP file.
3. Open the `EduPredict_AI` folder in VS Code.
4. Open Terminal → New Terminal.
5. Create a virtual environment:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   If PowerShell blocks activation, use Command Prompt in VS Code and run:

   ```bat
   .venv\Scripts\activate.bat
   ```

6. Install libraries:

   ```bash
   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt
   ```

7. Start the website:

   ```bash
   python -m streamlit run app.py
   ```

8. Streamlit should open a local browser tab. If it doesn't, copy the local URL printed in the terminal (usually `http://localhost:8501`) into your browser.

## How to demo it
- Open **Predictor**, change study hours, attendance, prior marks, assignments and sleep.
- Click **Predict performance**.
- Explain that the app uses a trained Random Forest Regressor.
- Open **Model Insights** and describe MAE, RMSE, R², the test split and feature importance.
- Open **About the Project** to explain limitations and future work.

## Interview talking points
- This is a regression task because the target is a continuous score.
- Random Forest combines many decision trees and averages their predictions.
- MAE is average absolute error in score points; RMSE penalizes larger errors more; R² measures fit relative to a baseline.
- The model is evaluated on held-out test data.
- Feature importance is model-specific and does not imply causality.
- The study suggestions are rule-based, not generated by a large language model. A future version could integrate a generative AI API, with privacy and safety controls.
